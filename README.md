# EGX Intelligence

Android-first, white-label EGX market intelligence starter.

- `prototype/index.html`: responsive interactive browser prototype.
- `android/`: Kotlin + Jetpack Compose Android starter.
- `docs/DELIVERY_STATUS.md`: delivery scope and production gates.
- `.github/workflows/deploy-pages.yml`: optional Cloudflare Pages workflow.

Open `prototype/index.html` in a browser. All figures are fictional demo data, not live EGX quotes. The Android source is a starter, not a signed APK.

Production requires Egyptian legal/FRA review, licensed market data and redistribution rights, backend/authentication, audit/security controls, UAT and release signing. No brokerage execution is enabled.
